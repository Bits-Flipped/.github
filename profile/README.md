# Bits Flipped LLC

**AI-accelerated modeling & simulation and GPU computing** — Colorado Springs, CO

We build simulation infrastructure for sensor and radar system analysis, backed by our own GPU compute cluster.

## What we're building

**⚡ GPU-accelerated sensor simulation** — Monte Carlo radar performance studies (detection statistics, RF propagation, multi-sensor fusion) that run thousands of scenario excursions in parallel instead of overnight.

**📋 Declarative scenario framework** — sensors, platforms, geometries, and measures of effectiveness defined in a validating, composable schema. Design a study, don't script one.

**🤖 LLM-assisted scenario workflows** — natural-language scenario generation and results analysis, built AI-first on top of the schema. Hybrid local/cloud inference on our own hardware.
